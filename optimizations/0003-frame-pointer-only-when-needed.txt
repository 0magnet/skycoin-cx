0003 Pass the frame pointer only to functions that need it
Status: proposed. Measured by hand, not built.

Where: t3-cx-compiler-llvm/llvm.go, instrCall and instrCallFrame (line 812).

Problem: the CX LLVM compiler gives every CX function an extra parameter fp,
the address of its frame in CX memory. Before every call, the calling
function checks fp + frame size against the stack end and stops the program
if it is past it. After optimization most frames live in registers, so fp is
used only for this check, and it costs two callee saved registers.

Change: pass fp only to functions whose frame stays in CX memory. Drop the fp
check where the largest frame times the depth limit fits the stack, because
the depth check fires first.

Measured (user cycles, two code layouts, instructions per call):
  fib  9.16G/8.04G, 16.8 per call -> 5.42G/5.57G, 12.0 per call
       (C 6.72G/6.66G, 11.0 per call), about 0.8x C
  ackermann  no gain. Its cost is the depth check, see 0004.
